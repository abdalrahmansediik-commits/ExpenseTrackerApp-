# ExpenseTrackerApp-
تطبيق "مقسم الميزانية" هو مساعدك المالي لتتبع دخلك ومصاريفك اليومية بسهولة. يتميز بلوحة تحكم ذكية لعرض رصيدك، تصنيف النفقات (طعام، فواتير، ترفيه)، ورسوم بيانية مبسطة لفهم أين تذهب أموالك بدقة. واجهة عصرية تدعم الوضع الداكن وتضمن خصوصية بياناتك محلياً على هاتفك. حمله الآن لتحكم أفضل بأموالك!
